## 描述（4,000 字符）

```
先说招牌：这是一位给小说脱水的 AI 编辑。

追更的人都懂——日更八千，干货两千。这章开头复述上章，下章开头复述这章；设定第三次讲解，功法第四次冲击窍穴；擂台又开打了，群众又倒吸凉气了。书是好书，就是泡在水里。

故事模式干的就是拧干这件事：把书脱水，把故事留下。

【一键脱水，力度四档可调】
复述、重复讲解、擂台车轮、群体震惊这类水文，遇到就压。一个旋钮从「轻扫一下」拧到「别废话赶紧推剧情」。剧情、人物、爽点、伏笔一个字不动——砍掉的只有水。

【顺手把文笔也修了】
错别字、病句顺手治；「倒吸一口凉气」「嘴角勾起一抹冷笑」这类写烂的套话直接重写。也可以反着来：开文笔扩写，把干瘪的打斗补成拳拳到肉的名场面——扩的是表现力，不是字数。

【什么语言的书都能读】
整本翻成中文、给省掉主语的日轻补上「谁在说话」，都是基本功。还嫌不够？一句话自定义：「文言文翻成白话文，定场诗判词原样保留」——照办。

【书从哪来都行】
本地 TXT 直接拖进来；或者只报个书名——贴链接、提站名、丢几个关键词，它自己上网找。天涯长帖、邮件串这种没章节的连续文本，勾一下「非章节小说」照读不误。

【正经阅读器】
11 套主题，字号、字距、行距、段距全可调；目录、书签、沉浸模式一个不少，读到哪自动记住，章节随时导出离线存档。

合上书，它还是一把好手。

【模型随便挑】
OpenAI、Anthropic、Google、DeepSeek、Mistral、xAI……200+ 家服务商、7000+ 个模型随便切，自建 / 本地 API 也支持，填上 Key 就能用。

【查资料不用自己开二十个标签页】
三档力度：快速搜一下要个事实；标准搜索要个靠谱答案；深度调研把问题拆开、逐个子话题搜过去读过去，答案连出处一起给你。

【浏览器替你跑腿】
「帮我把这几样东西加进 Target 购物车。」一句话说完，它自己开浏览器、挨个搜索、挨个加购。聊天一边、浏览器一边，点哪填哪全程看得见；验证码、登录、支付一到，立刻把方向盘还给你。

【对话自己会整理】
聊过的自动起标题、自动打彩色标签，标签分组一屏看全；搜一下就能翻出半个月前的对话，旧账批量归档。

【回答不是一坨纯文本】
代码带高亮，公式排版像教材，流程图、数据图表直接在对话里成图。

【还有些顺手的小东西】
• 截图、文档拖进对话就能聊
• 每个对话单独调参：模型、温度、最大 token、系统提示词
• 斜杠命令切模式，手不离键盘
• MCP 工具服务器
• 回答可以读给你听
• 深色 / 浅色 / 跟随系统

Key 是你自己的，模型随你挑，全程在你自己的电脑上跑。开源（MIT）。

反馈与建议：https://github.com/upwindchange/Autai/issues
```
