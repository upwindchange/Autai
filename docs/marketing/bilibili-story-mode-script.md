口播：

> 兄弟们，我最近干了件大事——我烧了一百亿 token，把一批网文作者，批量送去了三体世界。
>
> 让他们亲身体验一下，什么叫，脱水。
>
> 一百亿 token 什么概念？大概是我一个人，给半个数据中心的电费账单做了贡献。
>
> 为什么要这么干？咱们看网文的都懂——

备选开头 A（「不要回答」体，更玩梗）：

> 不要弃书！不要弃书！书友们，如果你还在一目十行地追更——不要弃书！
>
> 因为我已经替你们，把那个作者，送去三体世界脱水了。

> 如果一本五百万字的网文，真正是故事的只有三百万字——剩下的两百万字，都是水。
>
> 我烧了一百亿 token，把这两百万字，蒸发掉了。

## ④ 核心演示（1:10–2:20）

画面：全程录屏——脱水前后字数对比、套路勾选面板、扩写前后对比、翻译/找书、阅读器翻页。每换一个功能切一次转场，别用一个长录屏糊满 70 秒

口播：

> 它认识的水文套路，16 大类 85 种：复述前情、擂台车轮、群体震惊、降智反派反复送人头……全都门儿清，还能逐个点名。
>
> 所以它不是在删字数，它是在对注水网文执行古筝行动——纳米丝一拉，水字身首异处，剧情毫发无伤。
>
> 有人问：万一把我爱看的删了呢？放心，剧情、人物、伏笔一个字不动。要是你就想看打擂台，行，单点保留——好这口的兄弟，我尊重。
>
> 它还能反着用：开「文笔扩写」，把一句「大战三百回合」，扩成拳拳到肉的名场面。扩的是表现力，不是字数——不是给你补两章环境描写。
>
> 看日轻的兄弟也回来：省掉主语的对话，AI 直接补上「谁在说话」，还能整本翻译。甚至一句话自定义——「文言文翻白话，定场诗原样保留」，它真照办，比某些编辑还听话。
>
> 书的来源随便给：本地 TXT 直接拖；只报书名也行，贴个链接、提个站名，它自己上网找。天涯长帖这种没章节的，勾一下「非章节小说」，照读。
>
> 脱完的书装进正经阅读器：11 套主题、目录书签、断点续读，章节随时导出离线。

## 发布小贴士

- **封面**：大字报风格——「500 万字 → 300 万字」脱水前后数字对比，右下角小字「剧情一字未动」。数字梗封面在读书区点击率稳定。
- **置顶评论**：放下载链接 + 两句话 FAQ：「需要自己的 API Key（哪家的都行）」「本地模型也支持」。提前堵住「怎么用」刷屏。
- **弹幕/评论预判与回法**：
  - 「AI 删错/误伤怎么办」→ 回：剧情伏笔一字不动，85 个套路开关可单点保留，想看打擂台就留着打擂台。
  - 「这不就是洗稿吗」→ 回：自己改自己的书自己看，本地处理不传播，阅读自由。
  - 「百亿 token 真的假的」→ 回：约等于。主要是半个数据中心的电费（笑）。
- **恰饭观感**：口播里「我搓的开源软件」这句保住，B 站用户对「作者自荐 + 开源免费」宽容度极高，比接商单的转化好。
